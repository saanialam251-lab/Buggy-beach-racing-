# Beach Racing Legends

The app now includes a modular 3D beach environment:

- Circular race road with inner and outer curbs.
- Repeated road lane markings.
- Eight side-by-side multi-floor beachfront buildings with windows, doors, roofs, and colored facades.
- Palm trees, ocean water, sand, street lamps, emissive lamps, fog, shadows, and lighting.
- Reusable `BeachEnvironment` builder used by the Three.js car scene.

Run with:

```bash
npm install
npx expo start
```

The 3D cars and buildings are original procedural geometry. Exact Lamborghini, Porsche, or BMW models require properly licensed `.glb`/`.gltf` assets and manufacturer permissions.
